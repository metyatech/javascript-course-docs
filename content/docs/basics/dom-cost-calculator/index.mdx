<Section
    title="一緒に料金計算機を作ろう"
    goal="HTMLの部品を取得し、ボタンを押したときに料金を計算して表示できるようになります。"
>

講師と一緒に、HTMLとJavaScriptを上から順番に書きます。

### HTMLを書く

まず、完成したHTMLを用意します。

```html
<p>大人1人500円、子供1人300円です。</p>

<p>
    大人
    <input id="adult" type="number" value="0">
    人
</p>

<p>
    子供
    <input id="child" type="number" value="0">
    人
</p>

<button id="button">計算</button>

<p>
    合計
    <input id="total" value="0">
    円
</p>

<script src="index.js"></script>
```

それぞれの名前は次の部品を表します。

- `adult`：大人の入力欄
- `child`：子供の入力欄
- `button`：計算ボタン
- `total`：合計欄
- 最後の`script`で`index.js`を読み込みます

### JavaScriptを書く

次の順番で、講師と一緒に`index.js`へ追加します。

### 1. 大人の入力欄を取得する

```javascript
let adult = document.querySelector('#adult');
```

`id="adult"`の入力欄を取得し、`adult`という名前で使えるようにします。

### 2. 子供の入力欄を取得する

```javascript
let child = document.querySelector('#child');
```

同じように、子供の入力欄を`child`という名前で使えるようにします。

### 3. 計算ボタンを取得する

```javascript
let button = document.querySelector('#button');
```

`id="button"`の計算ボタンを取得し、`button`という名前で使えるようにします。

### 4. 合計欄を取得する

```javascript
let total = document.querySelector('#total');
```

`id="total"`の合計欄を取得し、`total`という名前で使えるようにします。

ここまで書いたら、入力欄の内容を読む書き方を確認します。`adult.value`は大人の入力欄の内容、`child.value`は子供の入力欄の内容です。`total.value`へ代入すると、合計欄の表示を書き換えられます。

### 5. ボタンを押したときの処理を書く

```javascript
button.addEventListener('click', function () {

});
```

先ほど取得した`button`が押されたとき、`{`と`}`の間に書いた処理が実行されます。

### 6. 料金を計算して合計欄へ表示する

波括弧の中へ次を追加します。

```javascript
total.value = adult.value * 500 + child.value * 300;
```

大人の人数に500、子供の人数に300を掛けて足し、結果を合計欄へ表示します。

### 完成したindex.js

最後に、完成した`index.js`を確認します。

```javascript
let adult = document.querySelector('#adult');
let child = document.querySelector('#child');
let button = document.querySelector('#button');
let total = document.querySelector('#total');

button.addEventListener('click', function () {
    total.value = adult.value * 500 + child.value * 300;
});
```

大人の入力欄に`1`、子供の入力欄に`2`を入力して、**計算**を押します。合計欄が`1100`になれば完成です。

### 演習1 リセットボタンを追加しよう

<Exercise>

一緒に完成させた料金計算機へ、リセット機能を追加しましょう。料金計算機全体を最初から作り直さず、完成している料金計算機へ次の追加だけを行います。

料金計算機に「リセット」ボタンを追加します。リセットボタンを押すと、大人、子供、合計のすべてが`0`に戻るようにします。

計算ボタンの後へ、次のHTMLを追加します。

```html
<button id="reset">リセット</button>
```

次に、`id="reset"`のボタンを取得し、クリックされたときに3つの`.value`へ`0`を代入する処理を、既存の計算ボタンのイベントより後へ追加します。

大人に`2`、子供に`3`を入力して、**計算**を押します。次に**リセット**を押し、大人、子供、合計がすべて`0`になれば完成です。

<Hint>

`reset`ボタンを`document.querySelector`で取得します。そのあと、クリックイベントの中で`adult.value`、`child.value`、`total.value`へ`0`を代入します。

</Hint>

<Answer>

HTMLでは、計算ボタンの後へ次を追加します。

```html
<button id="reset">リセット</button>
```

JavaScriptでは、既存の`adult`、`child`、`button`、`total`を宣言した後に`reset`を追加します。リセットイベントは、既存の計算ボタンのイベントより後へ追加します。

```javascript
let reset = document.querySelector('#reset');

reset.addEventListener('click', function () {
    adult.value = 0;
    child.value = 0;
    total.value = 0;
});
```

</Answer>

</Exercise>

### 演習-発展1 幼児料金を追加しよう

<Exercise>

演習1が終わり、さらに時間が余ったときだけ取り組みましょう。幼児1人100円の入力欄を追加し、幼児料金も合計へ加えます。

子供の入力欄の後へ、次のHTMLを追加します。新しいIDと変数名には`baby`を使い、ハイフンを含むIDは使いません。

```html
<p>
    幼児
    <input id="baby" type="number" value="0">
    人
</p>
```

次に、幼児の入力欄を取得し、合計式へ幼児料金を追加します。

大人`1`、子供`2`、幼児`3`を入力して、合計が`1400`になれば完成です。

```text
500 + 600 + 300 = 1400
```

<Hint>

`id="baby"`の入力欄を取得します。合計式へ`baby.value * 100`を足してください。

</Hint>

<Answer>

次の変数を、既存の入力欄の変数を宣言した後へ追加します。

```javascript
let baby = document.querySelector('#baby');
```

現在の短い1行の計算式を、次の複数行の式へ置き換えます。

```javascript
total.value =
    adult.value * 500 +
    child.value * 300 +
    baby.value * 100;
```

演習1のリセットボタンも追加済みの場合は、リセット処理へ次の1行も追加します。

```javascript
baby.value = 0;
```

</Answer>

</Exercise>

<Recovery title="動かないとき">

動かないときは、HTMLの`id`とJavaScriptの`#`以降の名前が同じか確認します。あわせて、`.value`と`'click'`の書き間違いがないか確認しましょう。

</Recovery>
