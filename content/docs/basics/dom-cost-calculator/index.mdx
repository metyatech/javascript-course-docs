まず完成形を動かして、作るものを確認しましょう。JavaScriptからHTMLの部品を扱う仕組みをDOMと呼びます。

<CodePreview
    sourceId="cost-calculator-complete"

    jsVisible={false}
    previewVisible={true}

>
```html
<p>大人1人500円、子供1人300円です。</p>

<p>
    大人
    <input id="adult" type="number" value="0">
    人
</p>

<p>
    子供
    <input id="child" type="number" value="0">
    人
</p>

<button id="button">計算</button>

<p>
    合計
    <input id="total" value="0">
    円
</p>
```

```javascript
let adult = document.querySelector('#adult');
let child = document.querySelector('#child');
let button = document.querySelector('#button');
let total = document.querySelector('#total');

button.addEventListener('click', function () {
    total.value = adult.value * 500 + child.value * 300;
});
```
</CodePreview>

大人の入力欄に`1`、子供の入力欄に`2`を入力して、**計算**を押します。

<Verify>合計欄が`1100`になればOKです。</Verify>

<Section
    title="使う書き方は3つだけ"
    goal="HTMLの部品を取得し、内容を読み、ボタンを押したときに表示を書き換えられるようになります。"
>

### 1. HTMLの部品を取得する

```javascript
let adult = document.querySelector('#adult');
```

`document.querySelector('#adult')`で、`id="adult"`が付いたHTMLの部品を取得します。

### 2. `.value`で内容を読む・書き換える

```javascript
adult.value
```

`.value`を付けると、入力欄に入っている内容を読めます。

```javascript
total.value = 1000;
```

`.value`へ代入すると、入力欄に表示されている内容を書き換えられます。

### 3. ボタンを押したときに処理する

```javascript
button.addEventListener('click', function () {
    // ボタンを押したときの処理
});
```

**計算**ボタンを押したとき、`{`と`}`の間に書いた処理が実行されます。

</Section>

<Section
    title="料金計算機を作ろう"
    goal="入力欄の人数を読み、ボタンを押したときに合計欄を書き換えます。"
>

ここでは、講師と一緒にHTMLとJavaScriptを上から1行ずつ書いて完成させます。

### HTMLを書く

次のHTMLを用意します。大人、子供、計算ボタン、合計欄にそれぞれ`id`が付いています。

```html
<p>大人1人500円、子供1人300円です。</p>

<p>
    大人
    <input id="adult" type="number" value="0">
    人
</p>

<p>
    子供
    <input id="child" type="number" value="0">
    人
</p>

<button id="button">計算</button>

<p>
    合計
    <input id="total" value="0">
    円
</p>
```

### JavaScriptを書く

次の順番で、コードを1つずつ追加します。

### 1. 大人の入力欄を取得する

大人の入力欄を`adult`に入れます。

```javascript
let adult = document.querySelector('#adult');
```

### 2. 子供の入力欄を取得する

子供の入力欄を`child`に入れます。

```javascript
let child = document.querySelector('#child');
```

### 3. 計算ボタンを取得する

計算ボタンを`button`に入れます。

```javascript
let button = document.querySelector('#button');
```

### 4. 合計欄を取得する

合計欄を`total`に入れます。

```javascript
let total = document.querySelector('#total');
```

### 5. ボタンが押されたときの処理を書く

`button`に`addEventListener`を書き、ボタンを押したときに処理を実行します。

```javascript
button.addEventListener('click', function () {
    // ボタンを押したときの処理
});
```

### 6. 合計欄へ計算結果を代入する

`{`と`}`の間に、計算式をそのまま`total.value`へ代入します。

```javascript
total.value = adult.value * 500 + child.value * 300;
```

6段階をつなげた完成形は次のとおりです。

```javascript
let adult = document.querySelector('#adult');
let child = document.querySelector('#child');
let button = document.querySelector('#button');
let total = document.querySelector('#total');

button.addEventListener('click', function () {
    total.value = adult.value * 500 + child.value * 300;
});
```

大人の入力欄に`1`、子供の入力欄に`2`を入力して、**計算**を押します。

<Verify>合計欄が`1100`になれば完成です。</Verify>
