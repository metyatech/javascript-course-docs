<Section
    title="一緒に料金計算機を作ろう"
    goal="HTMLの部品を取得し、ボタンを押したときに料金を計算して表示できるようになります。"
>

講師と一緒に、HTMLとJavaScriptを上から順番に書きます。

### HTMLを書く

まず、完成したHTMLを用意します。

```html
<p>大人1人500円、子供1人300円です。</p>

<p>
    大人
    <input id="adult" type="number" value="0">
    人
</p>

<p>
    子供
    <input id="child" type="number" value="0">
    人
</p>

<button id="button">計算</button>

<p>
    合計
    <input id="total" value="0">
    円
</p>

<script src="index.js"></script>
```

それぞれの名前は次の部品を表します。

- `adult`：大人の入力欄
- `child`：子供の入力欄
- `button`：計算ボタン
- `total`：合計欄
- 最後の`script`で`index.js`を読み込みます

### JavaScriptを書く

次の順番で、講師と一緒に`index.js`へ追加します。

### 1. 大人の入力欄を取得する

```javascript
let adult = document.querySelector('#adult');
```

`id="adult"`の入力欄を取得し、`adult`という名前で使えるようにします。

### 2. 子供の入力欄を取得する

```javascript
let child = document.querySelector('#child');
```

同じように、子供の入力欄を`child`という名前で使えるようにします。

### 3. 計算ボタンを取得する

```javascript
let button = document.querySelector('#button');
```

`id="button"`の計算ボタンを取得し、`button`という名前で使えるようにします。

### 4. 合計欄を取得する

```javascript
let total = document.querySelector('#total');
```

`id="total"`の合計欄を取得し、`total`という名前で使えるようにします。

ここまで書いたら、入力欄の内容を読む書き方を確認します。`adult.value`は大人の入力欄の内容、`child.value`は子供の入力欄の内容です。`total.value`へ代入すると、合計欄の表示を書き換えられます。

### 5. ボタンを押したときの処理を書く

```javascript
button.addEventListener('click', function () {

});
```

先ほど取得した`button`が押されたとき、`{`と`}`の間に書いた処理が実行されます。

### 6. 料金を計算して合計欄へ表示する

波括弧の中へ次を追加します。

```javascript
total.value = adult.value * 500 + child.value * 300;
```

大人の人数に500、子供の人数に300を掛けて足し、結果を合計欄へ表示します。

### 完成したindex.js

最後に、完成した`index.js`を確認します。

```javascript
let adult = document.querySelector('#adult');
let child = document.querySelector('#child');
let button = document.querySelector('#button');
let total = document.querySelector('#total');

button.addEventListener('click', function () {
    total.value = adult.value * 500 + child.value * 300;
});
```

大人の入力欄に`1`、子供の入力欄に`2`を入力して、**計算**を押します。合計欄が`1100`になれば完成です。

<Recovery title="動かないとき">

動かないときは、HTMLの`id`とJavaScriptの`#`以降の名前が同じか確認します。あわせて、`.value`と`'click'`の書き間違いがないか確認しましょう。

</Recovery>
