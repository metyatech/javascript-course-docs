<Section title="HTMLとJavaScriptをつなぐ" goal="HTMLと別ファイルのJavaScriptを、部品を読み込める順序でつなげられるようになります。">

HTMLとJavaScriptを別ファイルで作るときは、HTMLからJavaScriptファイルを読み込みます。

<Concept title="scriptタグのsrcとdefer">

`src`には読み込むJavaScriptファイルの名前を書きます。`defer`を付けると、HTMLの部品を読み終えてからJavaScriptが実行されます。今回は、JavaScriptが入力欄やボタンを探すため、`defer`を付けます。

</Concept>

<Action>

HTMLファイルの`<head>`の中に、次の`<script>`を書きます。

```html
<script src="index.js" defer></script>
```

`src="index.js"`で`index.js`を指定し、`defer`でHTMLを読み終えてから実行するようにします。

</Action>

<Recovery title="ボタンを押してもJavaScriptが動かないとき">

何も変わらない場合は、まずHTMLの`<script>`に`defer`が付いているか確認してください。次に、`src`のファイル名が実際のJavaScriptファイル名と一致しているか、イベントを登録するコードが書かれているかを確認します。

</Recovery>

<Verify>
HTMLとJavaScriptを別ファイルに分けても、JavaScriptがHTMLの入力欄やボタンを探せる準備ができます。
</Verify>

<QuickCheck>

`defer`を付ける理由を、次の中から選びましょう。

1. JavaScriptのファイル名を短くするため
2. HTMLの部品を読み終えてからJavaScriptを実行するため
3. ボタンの見た目を変えるため

<Hint>
JavaScriptが入力欄やボタンを探す順序に注目してください。
</Hint>

<Answer>
2の「HTMLの部品を読み終えてからJavaScriptを実行するため」です。部品がまだ読み込まれていないと、JavaScriptは探す対象を見つけられません。
</Answer>

</QuickCheck>

<Checkpoint>

- JavaScriptファイルを`src`で指定できる
- `defer`がHTMLの読み込み順序に関係することを説明できる
- JavaScriptファイル名と`src`の指定が一致している

</Checkpoint>

</Section>

<Section title="HTMLの部品をJavaScriptから見つける" goal="HTMLのidを目印にして、入力欄・ボタン・合計欄をJavaScriptから取得できるようになります。">

HTMLの部品をJavaScriptで使うには、まずその部品を見つけます。

<Concept title="idを目印にする">

HTMLの`id`は、JavaScriptから部品を探すための目印として使えます。今回は、部品を1つずつ指定するために`id`だけを使います。`id`を指定するときは、名前の先頭に`#`を付けます。

</Concept>

<Action>

HTML側で、入力欄・ボタン・合計欄に`id`を付けます。

```html
<input id="num-of-adults" type="number" min="0" value="0">
<input id="num-of-children" type="number" min="0" value="0">
<button id="calc" type="button">計算</button>
<input id="total-price" type="text" value="0" readonly>
```

</Action>

<Concept title="document.querySelector">

`document.querySelector`を使うと、HTMLの中から指定した部品を取得できます。今回は`#ID名`の形だけを使います。取得した部品を変数に入れておくと、その後の処理で同じ部品を使えます。

</Concept>

<Action>

JavaScriptで`#`と`id`を指定し、取得した部品をコンソールへ表示します。

```javascript
let numOfAdultsElem = document.querySelector('#num-of-adults');
let numOfChildrenElem = document.querySelector('#num-of-children');
let calcElem = document.querySelector('#calc');
let totalPriceElem = document.querySelector('#total-price');

console.log(numOfAdultsElem);
console.log(numOfChildrenElem);
console.log(calcElem);
console.log(totalPriceElem);
```

</Action>

<Verify>
コンソールに大人の入力欄、子供の入力欄、計算ボタン、合計欄の4つが表示されます。
</Verify>

<Recovery title="コンソールにnullが表示されるとき">

`null`が表示された場合は、HTMLの`id`と`document.querySelector`の中の名前を1文字ずつ比べてください。`#`の付け忘れや、大文字・小文字、ハイフンの違いがあると部品を取得できません。

</Recovery>

<QuickCheck>

次のHTMLから、大人の人数入力欄を取得するコードを書きましょう。

```html
<input id="num-of-adults" type="number" min="0" value="0">
```

<Hint>
`id`の名前の先頭に`#`を付け、`document.querySelector`の中に書きます。
</Hint>

<Answer>

```javascript
let numOfAdultsElem = document.querySelector('#num-of-adults');
```

`id`が`num-of-adults`なので、指定するときは`#num-of-adults`と書きます。`let`で変数に入れた部品を、あとで`.value`や`addEventListener`と組み合わせます。

</Answer>

</QuickCheck>

<Checkpoint>

- HTMLの部品に`id`を付けられる
- `document.querySelector('#ID名')`で部品を取得できる
- `null`のときにHTMLとJavaScriptの名前を比べられる

</Checkpoint>

</Section>

<Section title=".valueで内容を読む・書き換える" goal="入力欄の内容を読み取り、合計欄に新しい内容を表示できるようになります。">

部品を取得できたら、その部品に入っている内容を使います。

<Concept title=".value">

`numOfAdultsElem`は入力欄そのものです。`numOfAdultsElem.value`と書くと、入力欄に現在入っている内容を読み取れます。入力欄の内容を使いたいときは、部品の名前に`.value`を付けます。

</Concept>

<Action>

大人の入力欄を取得したあと、`.value`をコンソールへ表示します。

```javascript
let numOfAdultsElem = document.querySelector('#num-of-adults');

console.log(numOfAdultsElem.value);
```

大人の人数を入力してから実行し、入力した内容がコンソールに表示されることを確認します。

</Action>

<Verify>
入力欄そのものではなく、入力欄に現在入っている内容がコンソールに表示されます。
</Verify>

`value`は内容を読むだけでなく、値を代入して表示を書き換えることもできます。

<Action>

合計欄を取得し、`.value`へ`1000`を代入します。

```javascript
let totalPriceElem = document.querySelector('#total-price');

totalPriceElem.value = 1000;
```

</Action>

<Verify>
合計欄に表示されていた`0`が`1000`へ変わります。
</Verify>

| 書き方 | 動作 |
| --- | --- |
| `要素.value` | 現在の内容を読む |
| `要素.value = 値` | 表示されている内容を書き換える |

<QuickCheck>

「入力欄の内容を読む」と「合計欄の表示を書き換える」のコードを、次の表の空欄に当てはめましょう。

```javascript
let inputElem = document.querySelector('#input');
let outputElem = document.querySelector('#output');

console.log(inputElem.      );
outputElem.      = 1000;
```

<Hint>
読むときは`.value`を使います。書き換えるときは、左側に書き換えたい部品の`.value`を書きます。
</Hint>

<Answer>

```javascript
console.log(inputElem.value);
outputElem.value = 1000;
```

`inputElem.value`は入力欄の現在の内容を読み、`outputElem.value = 1000`は合計欄の表示を`1000`へ書き換えます。

</Answer>

</QuickCheck>

<Checkpoint>

- 入力欄の内容を`要素.value`で読める
- `要素.value = 値`で表示を書き換えられる
- 読む書き方と書き換える書き方を区別できる

</Checkpoint>

<Section title="クリックされたときに処理する" goal="計算ボタンを押したときだけ、合計欄の表示を変えられるようになります。">

入力欄を読んだり表示を書き換えたりする処理を、ボタンが押されたときに実行してみましょう。

<Concept title="イベントとaddEventListener">

クリックや入力など、Webページ上で起きた出来事をイベントと呼びます。`addEventListener`を使うと、ある部品でイベントが起きたときに処理を実行できます。

</Concept>

基本形は次のとおりです。

```javascript
要素.addEventListener('click', function () {
    // クリックされたときに実行する処理
});
```

| 部分 | 意味 |
| --- | --- |
| `calcElem` | どの部品で |
| `'click'` | 何が起きたとき |
| `function () { ... }` | 何を実行するか |

<Action>

まず、クリックされたら合計欄を固定値`1000`へ書き換えます。

```html

</p>

<p>

```


<Verify>
ページを開いただけでは`0`のままで、**計算**を押したときだけ合計欄が`1000`に変わります。
</Verify>

次に、クリックされたときに大人の入力内容を合計欄へ表示することもできます。

```javascript
calcElem.addEventListener('click', function () {
    totalPriceElem.value = numOfAdultsElem.value;
});
```

このコードでは、クリック時に大人の入力欄から`.value`で内容を読み、合計欄の`.value`へ代入しています。

<Recovery title="クリックしても表示が変わらないとき">

クリックしても変わらない場合は、`calcElem`が計算ボタンを取得できているか確認します。次に、`calcElem.addEventListener('click', function () { ... });`の中に、合計欄へ代入する処理が入っているか確認してください。

</Recovery>

次のコードの`'click'`は、何を表していますか。


1. 合計金額
2. クリックされたとき
3. HTMLの`id`

</Hint>

<Answer>

</Answer>

</QuickCheck>

</Checkpoint>

ここからは、時間に余裕がある人向けの発展課題です。演習1が完成してから進みましょう。

<Concept title="inputイベントと共通の関数">

`input`イベントは、入力欄の内容が変わったときに起きます。同じ計算を大人の入力欄と子供の入力欄の両方で使うため、計算処理を通常の関数宣言にまとめます。

</Concept>

<Action>

演習1の計算処理を`updateTotalPrice`という関数にまとめます。

```javascript
function updateTotalPrice() {
    let numOfAdults = numOfAdultsElem.value;
    let numOfChildren = numOfChildrenElem.value;

    totalPriceElem.value =
        numOfAdults * 500 + numOfChildren * 300;
}
```

</Action>

<Action>

大人と子供の入力欄に、同じ関数を`input`イベントの処理として登録します。

```javascript
numOfAdultsElem.addEventListener('input', updateTotalPrice);
numOfChildrenElem.addEventListener('input', updateTotalPrice);
```

同じ計算処理を2か所へコピーせず、関数名だけをそれぞれのイベントへ渡します。

</Action>

<Verify>
大人または子供の人数を変更した直後に、計算ボタンなしで合計金額が変わります。
</Verify>

```javascript
    totalPriceElem.value =

```
</CodePreview>

`updateTotalPrice`に計算処理を1つだけ書き、2つの入力欄から起きる`input`イベントに同じ関数を登録しています。初期表示は`0`なので、最後に関数を呼び出さなくても開始できます。

</Answer>

```javascript
let planElem = document.querySelector('#plan');
```

```javascript
    if (planElem.value === 'suite') {

    } else {

    }

    if (useTvElem.value === 'yes') {
        return 300;
    } else {
        return 0;
    }

    let tvPrice = getTvPrice();
    let guests = guestsElem.value;

    useTvCostElem.value = tvPrice;

}

useTvElem.addEventListener('change', updatePrice);
guestsElem.addEventListener('input', updatePrice);

updatePrice();
```
