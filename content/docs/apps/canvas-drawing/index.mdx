HTMLの`<canvas>`要素は、JavaScriptから線、図形、文字を描ける領域です。この仕組みをCanvasと呼びます。

前半はクリック位置に円を描くところまで全員で進めます。後半は、円以外に何を描くかを各自で選んで試します。

画面をクリックして、描かれた図形を確認してください。

```js
const canvas = document.querySelector('#canvas');
const context = canvas.getContext('2d');

canvas.width = document.documentElement.clientWidth;
canvas.height = document.documentElement.clientHeight;

canvas.addEventListener('click', (event) => {
    const size = Math.random() * 40 + 10;
    const hue = Math.random() * 360;

    context.beginPath();
    context.moveTo(canvas.width / 2, canvas.height / 2);
    context.lineTo(event.clientX, event.clientY);
    context.strokeStyle = `hsl(${(hue + 120) % 360} 100% 75%)`;
    context.lineWidth = size / 8;
    context.stroke();

    context.beginPath();
    context.rect(
        event.clientX - size,
        event.clientY - size,
        size * 2,
        size * 2
    );
    context.fillStyle = `hsl(${(hue + 60) % 360} 100% 65%)`;
    context.fill();

    context.beginPath();
    context.arc(
        event.clientX,
        event.clientY,
        size,
        0,
        Math.PI * 2
    );
    context.fillStyle = `hsl(${hue} 100% 65%)`;
    context.fill();

    context.font = `${size * 2}px sans-serif`;
    context.textAlign = 'center';
    context.textBaseline = 'middle';
    context.fillStyle = `hsl(${(hue + 180) % 360} 100% 75%)`;
    context.fillText('★', event.clientX, event.clientY);
});
```

<Section title="Canvasと描画用機能を取得する" goal="HTMLのCanvas要素と、Canvasに描くための機能一式をJavaScriptから取得します。">

Canvas要素を取得し、Canvasに描くための機能を取得します。

`script.js`に次の2行を入力します。

```js
const canvas = document.querySelector('#canvas');
const context = canvas.getContext('2d');
```

`getContext('2d')`で、Canvasに2次元の図形を描くための機能を取得します。取得したものを`context`に入れています。

<Verify>
ページを開いてもコンソールにエラーが出ず、Canvasに描く準備ができています。
</Verify>

<Checkpoint title="取得したものの確認">

- `canvas`にHTMLのCanvas要素が入っている
- `context`にCanvasへ描くための機能一式が入っている

</Checkpoint>

</Section>

<Section title="Canvasを表示領域と同じ大きさにする" goal="Canvasをブラウザの表示領域いっぱいに広げます。">

Canvasの初期サイズは幅300、高さ150です。今回はブラウザの表示領域いっぱいを描画に使います。

`document.documentElement.clientWidth`と`document.documentElement.clientHeight`で、ブラウザに表示されている部分の幅と高さを取得します。その値をCanvasの`width`と`height`に設定します。

`context`を取得するコードの下に、次の2行を入力します。

```js
canvas.width = document.documentElement.clientWidth;
canvas.height = document.documentElement.clientHeight;
```

<Verify>
ページを開くと、Canvasがブラウザの表示領域いっぱいに広がり、外側にスクロールバーが表示されません。
</Verify>

<Checkpoint title="サイズの確認">

- Canvasの幅に表示領域の横幅を設定している
- Canvasの高さに表示領域の高さを設定している
- サイズを設定するコードが、図形を描くコードより前にある

</Checkpoint>

<Section title="Canvasの座標を知る" goal="Canvasの左上を基準に、図形を置く座標を読めるようになります。">

Canvasの座標は、左上が基準です。

```text
(0, 0) ─────────→ x
  │
  │
  ↓
  y
```

- 左上が`(0, 0)`です。
- 右へ進むほどx座標が増えます。
- 下へ進むほどy座標が増えます。
- Canvasの図形は、座標で位置を指定します。

たとえば、`(300, 200)`は、左から300、上から200進んだ位置です。次は、この座標を円の中心として使います。

<Checkpoint title="座標の確認">

- Canvasの左上が`(0, 0)`である
- 右方向がx座標、下方向がy座標である
- 図形を置く位置をx座標とy座標で指定できる

</Checkpoint>

</Section>

<Section title="固定位置に円を描く" goal="指定した座標を中心に、Canvasへ円を1つ描きます。">

円を描く前に、使う命令の役割を確認します。

Canvasでは、まず「パス」という図形の形を作り、そのあとで塗ったり線を描いたりします。

`arc()`や後で使う`rect()`、`moveTo()`、`lineTo()`などは、パスに形を作るための命令です。形を作っただけではまだ塗られず、`fill()`や`stroke()`を実行すると実際に描かれます。

- `beginPath()`：それまで作っていたパスを空にして、新しいパスを作り始めます。
- `arc()`：現在のパスに円または円弧の形を追加します。
- `arc(中心のx, 中心のy, 半径, 開始角度, 終了角度)`の順に値を指定します。
- 第1引数は中心のx座標、第2引数は中心のy座標、第3引数は半径です。
- 第4引数は描き始める角度、第5引数は描き終わる角度です。
- JavaScriptでは円周率を`Math.PI`で取得できます。一周は`Math.PI * 2`です。
- `fillStyle`：図形を塗りつぶす色を指定します。
- `fill()`：現在のパスを塗りつぶして、実際に画面へ描きます。

固定位置の円を作るため、`canvas.height`を設定したコードの下に次を入力します。

```js
context.beginPath();
context.arc(300, 200, 30, 0, Math.PI * 2);
context.fillStyle = '#ff4d6d';
context.fill();
```

<Verify>
ページを開くと、左上から右へ300、下へ200進んだ位置を中心に、赤い円が表示されます。
</Verify>

<Checkpoint title="円の確認">

- `arc()`に中心のx座標、中心のy座標、半径、開始角度、終了角度を渡している
- `Math.PI * 2`で一周分の円を作っている
- `fill()`で円が画面に表示されている

</Checkpoint>

</Section>

<Section title="クリックした位置に円を描く" goal="クリックした位置を取得して、その場所に円を残します。">

固定位置に円を描いたコードを削除し、次のクリックイベントへ置き換えます。これで、決まった場所ではなくクリックした場所へ円を描けます。

クリックイベントの`event`には、クリックしたときの情報が入っています。

- `event.clientX`：表示領域の左端からクリック位置までの横方向の距離
- `event.clientY`：表示領域の上端からクリック位置までの縦方向の距離

次のコードを入力します。

```js
canvas.addEventListener('click', (event) => {
    context.beginPath();
    context.arc(
        event.clientX,
        event.clientY,
        30,
        0,
        Math.PI * 2
    );
    context.fillStyle = '#ff4d6d';
    context.fill();
});
```

画面内の複数箇所をクリックしてください。Canvasは、新しく図形を描いても、それまで描いたものは自動では消えません。そのため、クリックするたびに円が追加されます。

<Verify>
複数箇所をクリックすると、それぞれのクリック位置に円が残ります。
</Verify>

<Recovery title="円が表示されないとき">

- 症状：クリックしても円が表示されない場合は、次を順番に確認してください。
- 原因候補：HTMLの`id="canvas"`とJavaScriptの`'#canvas'`が一致しているか確認します。
- 原因候補：`<script>`に`defer`が付いているか確認します。
- 原因候補：`getContext('2d')`の`2d`が文字列になっているか確認します。
- 修正：開発者ツールのコンソールにエラーがあれば、表示された行を確認して直します。
- 修正：Canvasの幅と高さを設定するコードが、円を描くコードより前にあるか確認します。

</Recovery>

<Checkpoint title="共通部分の完成確認">

- クリックした位置に円が描かれる
- 複数回クリックしても、前の円が残る
- コンソールにエラーが表示されていない

</Checkpoint>

</Section>

<Section title="後半の演習" goal="円以外の描き方を選び、クリック位置に新しい図形を描きます。">

残り時間は、次の演習から好きなものを1つ以上選びます。各演習は独立しており、現在のクリックイベント全体を、各解答に掲載されているクリックイベント全体へ置き換えて試します。

`rect()`は、現在のパスに四角形を追加する命令です。次の順番で4つの値を指定します。

```text
rect(左上のx, 左上のy, 横幅, 高さ)
```

円と同じく、次の流れで描きます。

```text
beginPath()
↓
rect()
↓
fillStyle
↓
fill()
```

### 演習1：四角形

<Exercise>

現在のクリックイベント全体を、クリック位置を中心とする幅60、高さ40の四角形を描くクリックイベントへ置き換えます。クリックした場所に青い四角形が表示されれば成功です。

<Hint>
`rect()`の最初の2つの値は左上の位置です。クリック位置から横幅の半分と高さの半分を引くと、クリック位置を四角形の中心にできます。
</Hint>

<Answer>

`event.clientX - 30`と`event.clientY - 20`で左上の位置を作ります。横幅60と高さ40を指定すると、クリック位置が四角形の中心になります。`beginPath()`で新しいパスを作り、`rect()`で四角形を追加してから、`fill()`で塗りつぶします。

```js
canvas.addEventListener('click', (event) => {
    context.beginPath();
    context.rect(
        event.clientX - 30,
        event.clientY - 20,
        60,
        40
    );
    context.fillStyle = '#4cc9f0';
    context.fill();
});
```

</Answer>

</Exercise>

線を描くために、次の命令を使います。

- `beginPath()`：それまでのパスを空にして、新しいパスを作り始めます。
- `moveTo()`：現在のパスの開始位置を決めます。
- `lineTo()`：現在のパスに、指定した位置までの線を追加します。
- `strokeStyle`：線の色を指定します。
- `lineWidth`：線の太さを指定します。
- `stroke()`：現在のパスを線として実際に描きます。

### 演習2：線

<Exercise>

現在のクリックイベント全体を、画面中央からクリック位置まで線を描くクリックイベントへ置き換えます。画面中央とクリック位置が線でつながれば成功です。

<Hint>
`moveTo()`にCanvasの幅と高さを使った中央の座標を渡し、`lineTo()`に`event.clientX`と`event.clientY`を渡します。
</Hint>

<Answer>

`canvas.width / 2`と`canvas.height / 2`で画面中央を作り、クリック位置を線の終点にします。

```js
canvas.addEventListener('click', (event) => {
    context.beginPath();
    context.moveTo(
        canvas.width / 2,
        canvas.height / 2
    );
    context.lineTo(
        event.clientX,
        event.clientY
    );
    context.strokeStyle = '#ffd166';
    context.lineWidth = 4;
    context.stroke();
});
```

</Answer>

</Exercise>

文字を描くために、次の命令と設定を使います。

- `font`：文字の大きさとフォントを指定します。
- `textAlign = 'center'`：指定したx座標を文字の横方向の中心にします。
- `textBaseline = 'middle'`：指定したy座標を文字の縦方向の中心にします。
- `fillText()`：指定した文字を座標に描きます。

### 演習3：文字や絵文字

<Exercise>

現在のクリックイベント全体を、クリック位置に星を描くクリックイベントへ置き換えます。星がクリック位置を中心に表示されれば成功です。星は好きな文字、名前、絵文字へ変更して構いません。

<Hint>
`font`で文字の大きさを決め、`textAlign`と`textBaseline`でクリック位置が文字の中心になるようにしてから、`fillText()`で文字と座標を指定します。
</Hint>

<Answer>

`textAlign`と`textBaseline`を設定すると、指定した座標が文字の中心になります。`'★'`を好きな文字や絵文字へ変更して試してください。

```js
canvas.addEventListener('click', (event) => {
    context.font = '48px sans-serif';
    context.textAlign = 'center';
    context.textBaseline = 'middle';
    context.fillStyle = '#ffd166';
    context.fillText(
        '★',
        event.clientX,
        event.clientY
    );
});
```

</Answer>

</Exercise>

この演習では、クリックするたびに色と大きさが変わる円を描きます。

コードを書く前に、次の値の意味を確認します。

- `Math.random() * 40 + 10`は、10以上50未満の値です。`size`には円の半径を入れます。
- HSLの色相は0以上360未満で一周します。`hue`には色相を入れます。
- `hsl(色相 彩度 明度)`で色を指定できます。ここでは彩度を`100%`、明度を`65%`にします。

### 演習-発展1：色と大きさをランダムにする

<Exercise>

任意で、現在のクリックイベント全体を、色と大きさがランダムに変わる円を描くクリックイベントへ置き換えます。クリックするたびに、色と円の大きさが変われば成功です。

<Hint>
まず`size`と`hue`を作り、`size`を円の半径、`hue`を`hsl()`の色相に使います。円を描く流れは、固定位置の円と同じです。
</Hint>

<Answer>

`Math.random() * 40 + 10`で半径を、`Math.random() * 360`で色相を毎回作ります。`hsl()`の色相に`hue`を入れると、クリックごとに色が変わります。

```js
canvas.addEventListener('click', (event) => {
    const size = Math.random() * 40 + 10;
    const hue = Math.random() * 360;

    context.beginPath();
    context.arc(
        event.clientX,
        event.clientY,
        size,
        0,
        Math.PI * 2
    );
    context.fillStyle = `hsl(${hue} 100% 65%)`;
    context.fill();
});
```

</Answer>

</Exercise>

### 演習-発展2：描き方を組み合わせる

<Exercise>

任意で、上の候補から1つ選び、ここまで使った描き方を組み合わせて作ります。クリックした場所に作ったものが表示されれば成功です。

<Hint>
ロボットを選ぶ場合は、`rect()`で体や目の形を作り、`arc()`で頭の形を作ります。どちらも、クリック位置からx座標とy座標を計算して配置します。
</Hint>

<Answer>

次は、`arc()`で頭、`rect()`で体と目の形を作るロボットの例です。新しいCanvas APIは使わず、ここまでに説明した命令だけを組み合わせています。

```js
canvas.addEventListener('click', (event) => {
    context.beginPath();
    context.rect(
        event.clientX - 45,
        event.clientY,
        90,
        70
    );
    context.fillStyle = '#4cc9f0';
    context.fill();

    context.beginPath();
    context.arc(
        event.clientX,
        event.clientY - 35,
        35,
        0,
        Math.PI * 2
    );
    context.fillStyle = '#ffd166';
    context.fill();

    context.beginPath();
    context.rect(
        event.clientX - 14,
        event.clientY - 45,
        8,
        8
    );
    context.rect(
        event.clientX + 6,
        event.clientY - 45,
        8,
        8
    );
    context.fillStyle = '#07111f';
    context.fill();
});
```

</Answer>

</Exercise>
